# Sitev3
The work-in-progress v3.0.0 for [1nteresting.name](https://1nteresting.name). Based on [Quartz 5](https://quartz.jzhao.xyz).

## Changes from "Sitev2"
- Upgraded from Quartz 4 -> Quartz 5
- Introduction of [Semantic Versioning](https://semver.org)
- Rebuilt the visual theme from the ground up, it is now organised in a better manner and makes more frequent use of SCSS features. 
- Dates are now formatted in [ISO8601](https://www.iso.org/iso-8601-date-and-time-format.html) in all instances.
- Adjusted the Home page to include more information, and made the information presented more up-to-date.

> [!NOTE]
> Comments will be disabled until this site is deployed to the primary domain. This is to prevent duplicate Discussions that are created due to the path of pages changing in Quartz 5. Comments will be enabled again after Discussions are migrated to this new scheme.

> [!WARNING]
> Feature parity has not yet been achieved, that is the goal before this replaces the production site. Expect inconsistent behaviour.
